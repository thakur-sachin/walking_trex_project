# Ablation study

Every training run of the Trex walking task: what it changed, why, what was measured and what was learned.
Generated by `walk_rl/ablation_study.py` from `walk_rl/experiments/registry.yaml` and `outputs/walk_runs/` (2026-10-24 10:53). Do not edit by hand.

**How to read it.** Each run makes one change against its parent. Results are only comparable within one robot model: the simulator's robot changed six times as measurements came in. A value marked † was measured on a later model than the run trained on (the file was re-run after a model change). Each run is judged on the servo model it trained with: `ideal` is the PD drive of M0/M1, `lx16a` the fitted LX-16A model. Isaac numbers are walking at 0.10 m/s with randomization on; MuJoCo numbers are the deployed NumPy loop over friction × bus delay (median speed). "MuJoCo own model" is the same sweep with the robot rebuilt from the robot_config the run trained with, so every run is scored on its own robot; it shows transfer to a second engine, not a ranking across models. Old run configs: `git show <config>`.

## Run details

### v1 · M0 · rejected

- **Change:** first walking task; adaptive learning rate
- **Why:** baseline of the new task
- **Result:** circled 100-116 deg per 20 s and chattered while standing; later found to lean on its tail
- **Lesson:** an adaptive (rsl_rl-style) LR pins at its floor when the action std is small
- **Training:** 404 iterations, 4096 envs, 30 min, final action std 0.13

### v2 ← v1 · M0 · rejected

- **Change:** + yaw tracking, action_accel -0.5
- **Why:** stop the circling and the chatter
- **Result:** never learned; the penalty charged ~-3 per step for exploration noise
- **Lesson:** smoothness penalties on sampled actions punish exploration; use a command low-pass instead

### v3 ← v2 · M0 · rejected

- **Change:** command low-pass, action_accel -0.05, LR 1e-3
- **Why:** structural smoothing instead of a heavy penalty
- **Result:** best curve to iteration ~750, then collapsed in one update (KL 0.24 at std 0.13); best weights lost
- **Lesson:** keep a per-minibatch KL guard, best.pt and periodic checkpoints
- **Training:** 800 iterations, 4096 envs, 79 min, final action std 0.13

### v4 ← v3 · M0 · rejected

- **Change:** KL guard, best checkpoints, from scratch
- **Why:** v3's recipe without the collapse
- **Result:** 100 % survival and ~97 % tracking, but it walked on a tripod (tail on the ground); 0 % survival once that is a fall
- **Lesson:** make every implied rule an explicit termination; look at the frames before believing a metric
- **Training:** 900 iterations, 4096 envs, 74 min, final action std 0.14

### v6 ← v4 · M0 · rejected

- **Change:** any non-foot ground contact ends the episode; contact from forces
- **Why:** only the feet may touch the ground
- **Result:** stood still (foot air time 0.000 at iteration 200)
- **Lesson:** lifting a foot unaided is an exploration barrier

### v7 ← v6 · M0 · base

- **Change:** training-only harness (70 % body weight + righting torque, gone by iteration 450); stale-contact fix
- **Why:** get past the exploration barrier
- **Result:** first valid biped; 99 % survival at 0.10, 97 % tracking; heading drift up to 34 deg per 20 s
- **Lesson:** a curriculum that is removed during training can open a gait that RL does not find alone
- **Training:** 1000 iterations, 4096 envs, 51 min, final action std 0.26

### v8c ← v7 · M0 · superseded

- **Change:** heading observation, 3-frame history, delays, encoder offsets, pushes, new rewards
- **Why:** robustness to the real sensors and drift
- **Result:** heading change 0.7-2.4 deg per 20 s (v7 10-34); hard-sensor survival 88-97 % (v7 35-58 %)
- **Training:** 1000 iterations, 4096 envs, 66 min, final action std 0.28

### v8b ← v8c · M0 · rejected

- **Change:** v8c without pushes
- **Why:** which part of v8 did the work
- **Result:** best speed and hard-sensor survival; push survival 0.88 vs 0.95
- **Lesson:** observations, rewards and sensor delays did the heavy lifting; pushes buy push recovery only
- **Training:** 1000 iterations, 4096 envs, 88 min, final action std 0.26
- **Config:** `git show 1017f24:walk_rl/experiments/v8b_no_robustness.yaml`

### v8d ← v8c · M0 · base

- **Change:** gait clock frequency scales with speed
- **Why:** less sway at speed, less standing jitter
- **Result:** standing jitter halved; speed still capped at ~0.15-0.17 m/s (tibias on their 45 deg limit)
- **Lesson:** when every reward variant hits the same ceiling, check joint limits first
- **Training:** 1000 iterations, 4096 envs, 93 min, final action std 0.28
- **Config:** `git show 1017f24:walk_rl/experiments/v8d_gait_freq.yaml`

### v8e ← v8d · M0 · superseded

- **Change:** 16384 envs, 3000 iterations, pushes to 0.35 m/s
- **Why:** scale
- **Result:** survival 0.98-1.00, but action std ran away to 3.9
- **Lesson:** cap the action std (ppo.max_action_std 0.5)
- **Training:** 3000 iterations, 16384 envs, 523 min, final action std 3.89
- **Config:** `git show ca6f384:walk_rl/experiments/v8e_long_16k.yaml`

### v8e_lab ← v8e · M0 · superseded
