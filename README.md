# Walking Trex

A 3D-printed bipedal dinosaur robot that learns to walk in simulation and runs the learned policy on its own Raspberry Pi.

- **Robot:** 8 Hiwonder LX-16A serial bus servos (head, tail, hip / femur / tibia per leg), passive 4-bar ankles, a BNO055 IMU and a Raspberry Pi 4.
- **Training:** PPO in Isaac Sim 6.0.1, with an Isaac Lab 3.0 port of the same task that is bit-identical. The actor only sees what the robot can measure.
- **Servo model:** fitted to the real servos (0.46° RMS).
- **Before hardware:** every policy is also checked in MuJoCo through the exact control loop the Pi runs.

## Status (2026-10-19)

- **Policy:** v9d, trained on the fitted servo model.
  - Isaac Sim: survives 99–100% of 20 s runs at 0–0.25 m/s with randomization, and tracks 0.10 m/s at 99%.
  - MuJoCo: survives all 36 one-minute episodes across friction and bus-delay sweeps.
  - Below ~0.10 m/s it stands rather than walks.
- **Robot:** calibrated (ids, directions, zeros, servo EEPROM limits). The 25 Hz loop with real IMU and servo reads uses 20 ms of each 40 ms tick. Holding and single-joint moves have been tested in the air.
- **Next:** confirm the hip range by hand, then the policy on the robot with feet clear, then assisted standing.

## Quick start

```bash
export OMNI_KIT_ACCEPT_EULA=YES
PY=~/miniconda3/envs/isaac6/bin/python      # Isaac Sim stack
LAB=~/miniconda3/envs/isaaclab6/bin/python  # Isaac Lab, MuJoCo, fitting

$PY walk_rl/train.py --name v9c --iterations 1500 --task walk_rl/experiments/v9c_actuator.yaml
$PY walk_rl/evaluate.py --name v9c --actuator lx16a
$LAB pi_runner/render_mujoco.py --run v9c --schedule 0:2 0.15:8 0.20:8 0:4   # video in outputs/videos/
$LAB pi_runner/sim2sim.py --run v9c --frictions 0.3 0.5 0.8 --actuator lx16a
pi_runner/deploy.sh pi@trex.local v9c                                 # to the robot
```
